AMAR COMPUTER & MOBILE CENTER WEBSITE

Files:
- index.html = customer website
- admin.html = offer dashboard

Fast demo:
1. दोनों files GitHub repository में upload करें.
2. Website खोलने के लिए index.html/GitHub Pages इस्तेमाल करें.
3. admin.html खोलकर VI/BSNL/Recharge offers बदलें.
4. Save Offers दबाएँ.

IMPORTANT:
यह fast version browser localStorage इस्तेमाल करता है। इसलिए admin से किया गया बदलाव उसी browser/device में website पर दिखेगा। सभी customers को live offer बदलकर दिखाने के लिए backend/database (जैसे Firebase) या secure server/GitHub integration जोड़ना होगा.
